# Coding Agent

Supported target languages can include:
Python, Java, Kotlin, JavaScript, TypeScript, C, C++, C#, Go, Rust,
HTML, CSS, SQL, Bash and others.

Production responsibilities:
- inspect project
- understand dependencies/configuration
- create/edit files
- compile/build
- run tests
- parse diagnostics
- patch and retest
- refactor
- generate documentation

Code execution must use a sandbox with explicit permissions and resource limits.
