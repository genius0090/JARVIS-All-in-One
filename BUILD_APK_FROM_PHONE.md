# Build JARVIS Debug APK from a phone

1. Upload this project to a GitHub repository.
2. Open the repository on GitHub.
3. Open **Actions**.
4. Select **Build JARVIS Debug APK**.
5. Tap **Run workflow**.
6. Wait for the run to finish.
7. Open the completed run and download **JARVIS-debug-APK**.

The workflow builds `:app:assembleDebug` on GitHub's hosted runner.
No API keys are included.
